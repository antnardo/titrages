# Exemples

| Script | Ce qu'il montre |
| --- | --- |
| `01_acide_faible.py` | courbe, saut, tangentes, zone de virage d'un indicateur |
| `02_polyacides.py` | équivalences stœchiométriques et sauts visibles |
| `03_melange_titrant_faible.py` | un mélange par un titrant faible, et la dérivée |
| `04_pgfplots.py` | une courbe exportée en coordonnées pgfplots |
| `05_conductimetrie.py` | trois titrages conductimétriques, corrigés de la dilution |
| `06_redox.py` | le vanadium par le permanganate, et l'iodométrie |

```bash
uv run python examples/01_acide_faible.py
```
